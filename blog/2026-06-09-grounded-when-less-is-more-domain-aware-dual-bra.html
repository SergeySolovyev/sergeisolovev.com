When Less Is More: Domain-Aware Dual-Branch Recurrent Networks for LOB Mid-Price Prediction

2026-06-09 · Sergei Solovev, HSE University

A recurring assumption in LOB research is that more features and model diversity should improve predictive performance. The data suggests otherwise on both counts.

Working with 12,165 LOB sequences (12.1M timesteps), we found that a unidirectional GRU trained on 53 basic features achieves statistically equivalent performance to one trained on 219 engineered features — rolling statistics, EMAs, lag/difference transforms included. The recurrent hidden state appears to implicitly learn what the feature engineering pipeline was trying to make explicit. We call this the "feature sufficiency" effect.

The second finding is more counterintuitive: combining a sequential GRU with gradient boosting consistently degraded prediction quality. Not marginally — the negative ensemble effect held across experiments, directly contradicting the standard model-diversity argument.

The proposed architecture, DA-BiGRU-CNN, addresses a different problem: structural separation. Price and volume channels in a LOB carry distinct microstructure signals, and routing them through dedicated bidirectional GRU encoders before fusing via a multi-scale convolutional bottleneck (kernels 3, 5, 7) is a principled way to respect that. The GRU baseline alone achieves a weighted Pearson correlation of 0.266, outperforming LightGBM by 58%.

These results apply across centralized and on-chain LOB venues — the microstructure assumptions are the same.
